### 1. [去 AI 味模型：开源 4B 权重](https://linux.do/t/topic/3073575)

- **核心分类**：开源模型 / 微调实战
- **解决痛点**：主流模型写出的文本"AI 味"浓重（朱雀等检测一抓一个准），影响小说、文章类内容的发布与阅读体验。
- **技术要点与核心流程**：作者在其"落笔"项目（小说去 AI 味）基础上**从头重训**：在 SFT 之上加入**强化学习**（"更像人类的偏移"），已开源 4B 权重（HuggingFace: gugujiji/novel-humanize-4b），8B 版整理中，另有在线服务（luobi.18283745.xyz，注册送 2000 字 + 20 ldc 额度）。坦诚的工程细节：数据集未充分清洗、脏数据导致输出有语义错误与错别字，**需用 DeepSeek 大参数模型做二轮修正**；实用技巧——温度 1 改动不足时调到 1.15 可增强去味效果。
- **价值总结与实践建议**：397 赞/3990 浏览，当日 Develop 最热。"小模型专项去味 + 大模型纠错"的双段流水线是可直接抄的架构；对 AI 辅助写作且担心检测的创作者，可自部署权重（4B 消费级显卡可跑）。注意合规边界：该类工具用于规避平台检测存在政策风险。

### 2. [agent-purge：八大 Coding Agent 的提示词统一管控台](https://linux.do/t/topic/3074069)

- **核心分类**：开发工具 / Agent 工程
- **解决痛点**：同时使用 Codex、Claude Code、opencode、Grok、OMP、Hermes、Pi、ZCode 等多个 coding agent 时，system 提示词的替换/注入各自为政，缺乏统一管理入口。
- **技术要点与核心流程**：从 Pi-Purge 插件与 dsh-purge 移植拓展而来，一键"破甲"（替换/注入 system prompt），**会话独立**、支持本地 Web 控制台与"裸命令接管"（输入 `codex` 自动带提示词，但不支持会话内切换）。使用要点：先用"你是？"验证注入是否生效，不成功试 strict 模式；Pi 建议在会话最初热切换，避免被既有上下文影响。配套还有人设提示词库 some-magic。作者强调仅做提示词替换、不含违规内容。
- **价值总结与实践建议**：105 赞、fork 数超过 star（社区真实需求的风向标）。对维护多套 agent 人设/工作流的用户是刚需级工具；注意注入 system prompt 属于对抗 harness 默认行为的操作，各 harness 更新后可能失效，跟紧仓库更新。

### 3. [Wayline：用 ESP32 让 Windows 接入苹果原生 AirDrop](https://linux.do/t/topic/3074004)

- **核心分类**：开源硬件 / 跨生态互传
- **解决痛点**：Windows 与 iPhone 之间一直没有"原生级"的 AirDrop 体验，第三方网盘/微信传图都是妥协方案。
- **技术要点与核心流程**：思路是 **ESP32 做 USB 无线网桥**：设备以 AWDL（苹果无线直连）协议监听 AirDrop 流量，Windows 端通过 Rust 编写的桌面应用与 CLI 处理收发；固件适配 ESP32-S3 与 ESP32-C5-WiFi6（2.4/5GHz 双频段），支持信道切换；演示硬件为 Cardputer Adv（esp32s3）与微雪 ESP32-C5-WIFI6。作者自述代码大部分由 Codex 编写；Linux 端计划适配（上游已有 t4t5/owly）。
- **价值总结与实践建议**：硬件成本约几十元（一块 ESP32-C5），换来 Windows 原生收 AirDrop，跨生态刚需的优雅解法。现状提醒：仍在开发期、无发布版，需自行构建烧录（可让 AI 代劳）；购买硬件前先对照 README 确认型号。"AI 写代码 + 人做硬件集成"的开发范式样本也值得玩味。

### 4. [英语四六级/考研刷题机：永远不给你看答案的本地刷题应用](https://linux.do/t/topic/3073705)

- **核心分类**：开源应用 / 教育工具
- **解决痛点**：电子刷题的最大敌人是"看一眼答案就划走"——传统刷题软件把解析放在手边，重刷失去训练价值。
- **技术要点与核心流程**：8 月立项迭代至今，安卓/Windows 双端。核心理念：**永远不显示正确答案与解析**，靠重刷保持新鲜感；错题本只让 AI 分析"哪类能力缺失"而非讲解题目。功能栈：API 接入大模型（单词翻译/错题分析/题目导入/对话，支持多 key 自动拉模型列表）、ESQ 题库导入（可自提交录音/原文生成题库，模型辅助加速）、分题型练习与计时、单词本（形近词相邻排列辅助记忆）、**电脑端为主服务器的局域网多端进度同步**（扫码配对）。四六级与考研英一英二题库已在 GitHub 同步开源。
- **价值总结与实践建议**：60 赞/44 回复，考研/四六级人群的实用工具，"无答案重刷"的反常识设计是其灵魂。作者明示精力有限：接受 PR、issues 不保证及时响应——自用建议掌握题库导入流程（可导入任意 ESQ 题库扩展用途，如职称英语）。

### 5. [whiteboard-teacher-video：把讲解稿变成手绘动画视频的 Skill](https://linux.do/t/topic/3076817)

- **核心分类**：开源工具 / AIGC 视频创作
- **解决痛点**：知识类创作者想做 MG 动画（抖音百万级流量风口）门槛高——生图 API 贵、模板工具死板、改一个字重渲一整天。
- **技术要点与核心流程**：把讲解稿变成"手绘会动的画面"讲解视频：**图形由代码逐笔绘制、文字逐字写出、讲到哪画到哪**；五套风格可选；本地 Chrome 渲染，**零生图 API 成本**，任何改动秒级重渲。这是其"有声有色动效版"的迭代（前作已在社区发布），配 B 站实拍演示（GPS 是怎么工作的）；作者预告正在加 anatomy 3D 动效版本。
- **价值总结与实践建议**：44 赞/674 浏览。"代码即动画"路线（Manim 的平民化变体）规避了生图模型的成本与不稳定性，与当前 MG 动画流量红利正好咬合；做科普/知识账号的佬友可直接装 skill 试用，教学讲解与短视频引流两相宜。适合与 10-24 期介绍的 reveric 创作工作台互补（一个管剧本生产、一个管讲解成片）。
