### 1. [铁公鸡拔毛！OpenAI 发福利了！——Pro/Team 订阅费 1:1 返成 API 额度](https://linux.do/t/topic/3088794)

- **核心分类**：平台政策 / 订阅权益
- **解决痛点**：ChatGPT Plus/Pro 的订阅额度只能在聊天界面里用，想在 Codex 或自己的项目里调 API 得另掏一份钱——这是长期被吐槽的"一鱼两吃"。
- **技术要点与核心流程**：规则是 **按套餐金额 1:1 每月发放 API credits**：Pro $100 档每月送 $100、Pro $500 送 $500，Business 同理。领取路径：ChatGPT → Settings → Billing → `API credits benefit` → 关联 API Organization 领取；或直接去 `platform.openai.com/settings/organization/billing/overview`。**三个限制**要看清：① **订阅需满 7 天**才符合资格；② 首次**按当前账期剩余天数折算**（实测 pro200 首期只领到 40，另有用户领到 108，要下一周期才是全额 200）；③ **未用完不累计**，随续费每月重新发放。
- **价值总结与实践建议**：6048 浏览/370 赞，是当日唯一破 300 赞的技术相关帖。评论区三件事值得注意：@Lionheart_Wind 查证**超支后返回 HTTP 429 而不是产生额外账单**——这点打消了"领了会不会反被扣钱"的顾虑，可以放心去申请；@feek 反馈账单模块里看不到领取入口，楼主解释是**分批开放、耐心刷新**；@Adularia 一句"PLUS 用户：什么鸡拔毛来着"道出关键——**这个权益覆盖 Pro 及以上，Plus 没有**。建议：符合条件的先把额度领了（不用白不用），但别按"每月有全额"来规划预算，首期折算和"不累计"这两条会让你实际拿到的远低于标价。

### 2. [宝塔免费 Nginx 防火墙：静默上传用户文件、POST 可绕过、HTTP 拉脚本 root 执行](https://linux.do/t/topic/3089544)

- **核心分类**：安全 / 供应链与运维信任
- **解决痛点**：很多人把"免费防火墙"装在生产服务器上当第一道防线，却没人真的读过它的源码——这篇就是读完之后的结果。
- **技术要点与核心流程**：作者给出七条带行号的代码级证据：① **静默上传用户文件**——`free_waf_main.py` 的 `send_baota2()` 把命中规则的文件**全文** POST 给 `bt.cn/api/panel/btwaf_submit`，且 `return True` 永远不检查返回值、不留日志；8.4 前还是 http 明文，8.5 才改 https，但**面板界面从头到尾没有任何提示**。触发条件很松：点过一次「扫描木马」+ 站点有 .php 命中规则，而规则是 `str_rot13`、`base64_decode($_`、`eval(` 这种——现代 PHP 程序、WordPress 插件、任何加解密代码基本都躲不掉。② **POST 检测可绕过**：`4.7.lua` 里参数名**长度 > 64 字符**或叫 `kw`/`body`/`content`/`msg`/`file` 等就 `return false` 直接放行，实测 `kw=union select 1,2,3`、`body=<script>alert(1)</script>` 均放行（对照组常规参数能正常拦 XSS）。③ **HTTP 拉取云端脚本后不校验即以 root 权限执行**。④ 硬编码字符串 `hackcnm`——Webshell 命名为 `hackcnm.php` 或放在 `hackcnm/` 目录下即可**永久免检**。⑤ **假 PTR 绕过**：为不误伤蜘蛛做了 PTR 反查，但匹配是 `string.find(ptrdname,"baidu")` 这种无头无尾的模糊匹配（360 那条只要 PTR 含数字 `0` 就成立），一旦判定为蜘蛛就**跳过 18 项检测里的 14 项**，只留 4 项参数级检测。⑥ 能访问 `http://127.0.0.1/` 的任何进程（PHP curl、图片代理、webhook、被拿下的低权限进程、配置错误的本机反代）都能**清空 IP 黑名单**。⑦ 判断 Nginx 启动成功靠 `netstat -nltp | grep nginx | grep 80` 字符串匹配——非 80 端口的主机直接判死，PID 里带 80 也算成功。
- **价值总结与实践建议**：1670 浏览/75 赞，属于"赞数不高但含金量极高"的那类安全帖，作者明说自己是因为"作者明显知道漏洞但不打算修"才发出来提醒。实操建议三条：① 用宝塔免费 Nginx 防火墙的，**尽快卸载或停用**，有专业版用户反映部分问题在收费版同样存在；② 如果你点过「扫描木马」，默认认为站点源码已上传过云端，涉及敏感代码/密钥的**按泄露处理、改密换钥**；③ 别把这台机器的防护寄托在它身上——第②⑤⑥条意味着它拦不住针对性攻击，只挡得住扫描器噪音。顺带一提：它用 `eval(` 这种宽泛规则做木马查杀的思路，本身就是"高误报 + 静默上报"的组合，选型时对任何"免费安全产品"都该先问一句它往哪传数据。

### 3. [0u0-鹈鹕 PRO：0.26B 参数小模型，把"鹈鹕测试"刷成了行为艺术](https://linux.do/t/topic/3091229)

- **核心分类**：开源模型 / 评测方法论
- **解决痛点**：社区常用"能不能画好骑自行车鹈鹕的 SVG/HTML"当模型能力的土味 benchmark，而这个测试其实很容易被"背答案"蒙过去。
- **技术要点与核心流程**：0u0ai 搞了个 **0.26B（257M）参数**的 Llama 架构小模型，**无基座、从零训练**，唯一的技能是：对任意输入（中英文、乱码、表情、空文本都行）**完整输出 63617 字节的 `鹈鹕PRO.html`**，且经 llama.cpp 贪心解码验证**逐字节一致**。权重已开源（HF: `0v0ai/0u0-pelican-pro-0.2B-GGUF`）。作者的原话其实是吐槽："这也是我不喜欢以'鹈鹕测试'作为模型能力量化标准的原因。"
- **价值总结与实践建议**：3052 浏览/114 赞。回复区 @ChuJiuMao 把逻辑推到极致——"什么时候训练一个超小模型，专门用现在的测评数据当训练集，benchmark 直接打爆 Fable 5.5 和 GPT-bel"——这正是当下公开榜单面临的困境（呼应 10-28 期 Artificial Analysis v5 把 60% 权重换成私有集的做法）。@MinQ 补了一句"现在很多都是用的私有数据集"。结论很实在：**这类单点生成测试已经不具备区分度**，看到"某模型鹈鹕测试 SOTA"这种说法，先想想 0.26B 的模型也能满分。想玩可以下 GGUF 到本地跑，成本极低。

### 4. [【开源推广】这样的终端用起来不烧心——NyaTerm](https://linux.do/t/topic/3088438)

- **核心分类**：开源工具 / 远程终端
- **解决痛点**：WindTerm 停更一年左右，闪退和小毛病没人修，而它偏偏是很多人手感最对的那一个；市面上替代品要么重、要么不顺手。
- **技术要点与核心流程**：作者今年 5 月起照着 WindTerm 复刻功能，第一版用 **Tauri + WebView** 很快搓出来，但"大量文本输出、持续刷新、滚动、多终端并行"这类终端特化场景下 WebView 的性能瓶颈始终解决不了——于是**换框架重写**：v2 改为 **Rust + GPUI 原生桌面架构**（界面、终端渲染、连接管理全部原生，彻底去掉 WebView），已发布 **2.0.0 正式版**。作者坦言这基本等于重新开发了一遍：GPUI 里终端绘制、窗口管理、输入法、剪贴板、跨平台兼容都得重新实现。仓库：nyakang/nyaterm。
- **价值总结与实践建议**：1032 浏览/67 赞，评论区出现了"抓到作者本人"的名场面——@unclel 反馈跳板机功能在"前两天墙大杀四方"时帮了大忙，还点名 MCP 好用。给 WindTerm 用户的判断：这是**同类迁移路径里最对味的一个**（功能照着 WindTerm 复刻 + 原生性能），值得下个试试；但注意它是**刚从 WebView 重写完的 2.0.0**，输入法/剪贴板这类平台细节是新重写重灾区，先在非关键环境跑一周再切主力。有意思的是它和 10-28 期的 Motty × Viva 构成了对照：同样是受不了 Electron/WebView 的终端，一个选 Go 自研框架，一个选 Rust + GPUI，路线不同、结论一致。

### 5. [Gemini 4 Carbon：一句话 prompt 直接 one-shot 出 15 秒动效视频](https://linux.do/t/topic/3092142)

- **核心分类**：模型实测 / 生成式视频
- **解决痛点**：动效 / motion graphics 这类产出，以往要么找设计师、要么在 AE 里磨半天，模型能不能一句话出片是个很实际的检验点。
- **技术要点与核心流程**：用 Carbon-G（Gemini 4 Carbon EAP）跑一个 prompt——*"make a dynamic 15-second motion graphics video that shows what an incredible motion designer you are, like it's your showreel for a résumé. go all out"*——**one-shot 直接出片**，成品（webm）放在 PikPak 上分享（源自 Discord，**需要梯子才能打开**）。楼主的体感结论：效果比 Opus 5.5 好。
- **价值总结与实践建议**：1556 浏览/40 赞，@jmx 一句"这效果太好了吧呀"是评论区主流反应。两个保留意见：① 样片是楼主自己在 API 上跑的、**样本只有一条**，且"比 Opus 5.5 好"是主观体感，不是盲测；② Carbon 目前是 EAP（早期访问）阶段，样片托管在第三方网盘，能不能稳定复现不好说。想验证就自己拿同一个 prompt 跑一遍再下结论——生成式视频方差本来就大，一条样片说明不了水位。
