### 5. Panache：把 Markdown／LaTeX 变成手写稿的开源工具与 MCP 接入
[https://linux.do/t/topic/3223667](https://linux.do/t/topic/3223667)

- **核心分类**：Develop / 开源桌面工具、文档排版自动化与 MCP（2,113 浏览 / 296 赞 / 79 回复，短名单加权第一 s=88.9，作者 Nuits，主帖长文 + 多张成品截图，按社区要求 AI 润色内容以截图发出）。
- **解决痛点**：把 AI 回答整理成能交的手写稿，最烦的不是写内容而是排版——Markdown 的 `##`／`**` 要清掉、LaTeX 公式要排成分子分母上下分开、化学式上下标要落对位置，还想铺在自己拍的实验报告纸上。这帖把「清洗 → 转写 → 自定义纸张 → AI 客户端内直接调度」串成一条链，正好把「能生成」和「能顺手改」分开。
- **技术要点与核心流程**：① **清洗与转写**——从 AI 回答复制粘贴进 Panache，「编辑工具 → 整理文本」清掉标题前的 `##`、加粗的 `**`，常见 LaTeX 公式一并转写；「生成预览」后分子分母上下排开、根号横线盖到式子末尾，化学式 `SO_4^{2-}` 的 4 在右下、2− 在右上；成品示例包含两级 RC 网络电路与矩阵推导、化学式与离子电荷同页。② **自定义纸张**——拍一张空白实验报告纸上传让 Panache 识别横线，点线太淡 / 位置没认准可自己框书写区；斜着拍的纸也能顺着纸面横线走向排（作者用操作系统作业演示进程状态转换图与银行家算法资源分配表，箭头用手写风格 `->`、框线跟着字体取笔宽，表格横边与纸上横线同一走向）。③ **MCP 接入**——桌面版 v1.19.0 自带「应用设置 → 连接 AI 客户端」，复制配置接到惯用 agent harness 后可直接下指令，例如「把第 26～29 题排到这张信纸上。先给我看第 26 题的流程图，等我看完再导出整份 PDF」；长作业改一张图只预览那一页，前面调过的稿子按版本留在本机、可回看改之前的效果。④ **许可与平台**——AGPL-3.0；Windows / macOS / Linux / Android 有安装包，iOS 目前需自己编译，也可自部署网页版；MCP 随三个桌面版提供；GitHub 开源，作者欢迎把排崩的那一小段 Markdown 或 LaTeX 贴到 issue 反馈。
- **价值总结与实践建议**：社区反馈以收藏与好评为主，如实写：@chinajojo「卧槽这百分百好东西啊，有好几个都收费」、@farin3517「收藏一下，这不是我儿时的梦想吗？」、@tao0529「收藏一下，说不定哪天用的上」——**高赞区没有一条给出复现或效果验证**。作者「再编」自述的局限更要如实写：项目最初只是自己出于玩具目的做的、没想到需求意外的多，调研时发现同类开源项目还没有客户端和结合 AI 流程的能力才做下来；**「目前字体和仿真程度上肯定还有很长的路要走，MCP 也在尝试做一些相关的垂直场景优化」**；**「遗憾的是自己不懂写字机，所以也没有考虑过相关功能，希望以后有能人能满足各位的写字机需求」**——别把「手写生成」读成物理写字机输出。实践上：① 用前先看清用途与学术诚信边界（作者定位是「帮助自己解决课业负担」，把 AI 回答整理成手写稿属于排版辅助，能否用于提交作业由所在课程规则决定）；② 公式 / 表格 / 斜拍纸这类复杂排版先小样本验证再整份导出，作者明确欢迎把排崩的片段贴 issue；③ 想接 MCP 先确认客户端版本（v1.19.0+）与三个桌面版范围，iOS 需自编译、网页版可自部署；④ 版本留存是本机回看、不是云端同步，跨设备要自己备份；⑤ AGPL-3.0 有传染性，二次分发 / 商用前先读许可；⑥ 与 3222944（公司尽调 Skill）、3222848（Tools3000）同属 11-23 这批「借 AI 搓出来的开源工具」，可对照看 MCP / Skill 正在成为个人工具接入 Agent 的标准接口；这类推广帖同样要留意 3223252 提出的反面——客户端在全局 skill 里塞自己的 skill，接入前先看默认设置。
