### 1. [开源] PaperSearch（原 Paper Search CLI）更新：通过 CARSI 下载非 OA 文献，自动过 cloudflare 验证
[https://linux.do/t/topic/3146634](https://linux.do/t/topic/3146634)

- **核心分类**：资源荟萃 / 开源工具 · 学术文献检索与全文下载（当天唯一进榜的资源荟萃帖，短名单评分第 2，s=38.2）
- **解决痛点**：作者之前在站里发过 `paper-search-cli`，用来检索文献、期刊并抓取全文，但非 OA 文献只能靠出版社提供的 API key 下载——申请很麻烦、能覆盖的出版社也不多。要下学校订阅的非 OA 文献还有 CARSI 和 WebVPN 两条路：CARSI 国内高校基本都已加入、登录学校账号就能下，通用性好（本次已接入）；WebVPN 作者学校体验太差没接入，愿意一起测试的佬友可私聊。GitHub 上已有 `scansci-pdf` 等几个做 CARSI 的开源项目，但作者认为效果不理想：不能自动过验证、经常漏掉不少文献、浏览器还抢前台影响电脑正常使用、可视化界面也比较简陋——这次接入专门针对这几处做了优化。
- **技术要点与核心流程**：① 利用 CARSI 登录实现付费文献的**批量自动化下载**，适配主流 30 多家出版社并持续维护更新（出版社清单在主帖里是截图占位，未逐一列出）；② Cloudflare 墙自动过验证，过不了会弹通知、提示手动干预；③ 机构登录自动化，只在登录时手动输一次账号密码，后续大部分情况可复用；④ 胶囊窗口实时显示下载进度，并可在其中做设置配置；⑤ 需要登录时胶囊窗口会变色，提醒快速人工干预（也可在 Setting 里配系统通知）；⑥ 下载完毕给出下载情况总结。快速配置方面：装过旧版的要先 `npm uninstall -g paper-search-cli`（两个一起装会报 `EEXIST`），新包改名叫 `PaperSearch`、命令仍是 `paper-search`——把「请帮我安装 PaperSearch：`npm install -g papersearch`，再用 `paper-search skills update` 给你自己装上 Skill」发给 Agent，重开对话后说「请开始配置」来配置 CARSI 登录和 API Key。现有能力是「跟 AI 说一句话」得到文章摘要、正文内容、期刊影响因子、被引及参考文献，以及文献 PDF 和附录。后续计划三项：Markdown 全文包（抓 HTML/XML 后生成 Markdown 全文和正文图片）、支持所有 eduGAIN（CARSI 之外如 InCommon、UK federation，作者自己测不了、需要当地佬友帮忙）、WebVPN 下载（仍在评估）。下载失败或想支持某出版社可提 Issue，附上 `paper-search failures --format text` 的输出。
- **价值总结与实践建议**：95 浏览 / 15 赞 / 10 回复（归档快照值，索引表第 5 位），短名单评分第 2（s=38.2）。社区反馈：@LiuLiYu「这个好啊，感谢佬」，作者 @Dumplings 回「欢迎佬测试，现在还在优化，有问题随时跟我说，我再调整」，@Miomiomm 则泼了句冷水「Paywall 还是太烦人了，难以逾越的鸿沟」——这句吐槽恰好点出了工具的边界。三点如实说：① 它解决的是**「已有合法订阅权限但下载流程繁琐」**，不是绕过付费墙；@Miomiomm 说的 Paywall 鸿沟依旧在，别把它理解成免费下全网文献的通道；② 「适配 30 多家出版社」是作者自述、清单以截图占位给出，正文没有逐家列出，且作者自己说「还在优化」「欢迎测试」，属早期项目，实际覆盖率与成功率要按自己学校的 CARSI 身份实测，别按宣传直接当生产工具；③ 「把这段发给 Agent」的安装方式本质是让 AI 装上 Skill 并接管配置，涉及学校账号密码，建议先看清仓库与 Skill 行为、在测试环境跑通再用于正式文献下载；另外 CF 自动过验证失败时仍需人工干预，批量下载前要预留值守时间，别指望挂机全自动。

### 2. 【已成功】ChatGPT 官方礼品卡订阅方案（不用 App Store 方案，可以用国内卡）
[https://linux.do/t/topic/3150430](https://linux.do/t/topic/3150430)

- **核心分类**：Develop / 订阅支付路径 · 官方礼品卡兑换（短名单评分第 17，s=13.1）
- **解决痛点**：作者在论坛搜了很久，发现很少有人聊 ChatGPT 官方礼品卡订阅，于是自己实测一遍给社区一个方案。很多佬友订阅 ChatGPT 时常撞上 Apple 账号封控、没法及时订阅，通常做法是找 Apple 客服 battle、等 72 小时后再试，当然也可能直接把号封掉。ChatGPT 今年早些时候推出了礼品卡，据说可以订阅 GPT 以及买 credits，那么自然可以尝试用官方礼品卡来订阅。
- **技术要点与核心流程**：① 去 BestBuy 选购礼品卡，作者订的是 200 刀档，就买 200 刀的 giftcard；② 添加 MasterCard 付款，用的是招商银行万事达储蓄卡，经测试可以付款；③ Place Order，让 giftcard 发到自己的邮箱；④ 收到邮件点 View My E-GiftCard，可能出现异常页面，别慌，直接去 orders 里看，点 redeem now、输入 email 的 address，就能看到礼品卡，进去 view 一下可看到 PIN（送人则点 send gift）；⑤ 去 ChatGPT 官方输入 PIN 兑换——**这里一定一定要选上面的那个 ChatGPT，而不是 API organization**；⑥ 兑换成功后，在设置的 Billing 里可以看到多了 200 刀余额；⑦ 到 ChatGPT 订阅界面点想要的套餐，wallet balance 完全抵扣，直接 upgrade，订阅完成。
- **价值总结与实践建议**：433 浏览 / 11 赞 / 13 回复（归档快照值，索引表第 56 位），短名单评分第 17（s=13.1）。社区回复里 @yud25007 问「新渠道 不知道 a/ 那边有没有」，作者回「A\ 好像没有礼品卡，希望能出一个，这样可以猛猛订阅，不然每次被 ban 了之后卡就不太能再付的上了」；@Magentic 直接点出最关键的风险「关键是礼品卡封号就炸了，没渠道退款」。三点如实说：① 这是**一次个人成功实测**，不是官方渠道承诺——主帖没给出 BestBuy 礼品卡的条款、地区限制、退款政策，也没说明兑换后余额是否可跨区使用，照抄前先确认自己账号地区与礼品卡适用区一致；② @Magentic 的质疑是这条路径最硬的风险：礼品卡是预付余额，一旦账号被封就没有退款通道，200 刀一次性充进去等于把风险前置，不建议把长期订阅预算一次性压在礼品卡上，小额分批更稳；③ 「选 ChatGPT 而不是 API organization」是全文最关键的防错点，兑换页两个入口很像，选错余额会进 API 组织、无法抵扣订阅；另外这条路径只是绕开 Apple 账号封控，**并没有改变账号本身的风控状态**，作者自己也说「每次被 ban 了之后卡就不太能再付的上了」，别把它当成解决封号的方案。

### 4. 你们会关闭 Claude Code 的遥测吗？
[https://linux.do/t/topic/3147621](https://linux.do/t/topic/3147621)

- **核心分类**：Develop / 隐私与遥测配置 · CLI 环境变量（短名单评分第 15，s=13.5）
